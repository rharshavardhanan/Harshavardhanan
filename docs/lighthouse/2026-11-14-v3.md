## What changed to get here

The first measurement of the finished rebuild was home 83 to 85.

- **The loader's initials are simply there** instead of being drawn in. A drawn-in
  clip only counts as painted once fully revealed, which pushed the largest paint
  back by the length of the animation.
- **The loader and the fly-in are shorter**: out at 1.1 s (was 1.4 s), the
  panels land in 0.9 s, 60 ms apart (were 1.1 s, 90 ms).
- **The films wait for the panels to land** (posters show until then), so three
  films (0.8 MB each) no longer compete with the first screen.
- **Accessibility 96 → 100 on `/work/scp`:** the quote, half-lit before it is
  scrolled to, read as faint text below the fold. It now stays out of sight until
  its stretch of the page arrives. `e2e/a11y.e2e.ts` audits a project page with
  motion on to keep it that way.

## How to re-run

```bash
pnpm build && pnpm start --port 3300   # leave it running
CHROME_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  npx -y lighthouse@12 http://localhost:3300/ --chrome-flags="--headless=new" \
  --only-categories=performance,accessibility,best-practices,seo --view
```
