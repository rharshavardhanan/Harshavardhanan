# Redesign pass: implementation plan

Brief: `docs/brief-redesign.md`. Decisions: design doc section 8. Six phases, built
back to back, one local commit each. Tests are rewritten where the layout they describe
changes; none are dropped.

**Global constraints:** five type sizes only (display, h2, h3, body, label), nothing
under 13px; colour only through the five roles; at most one hairline per section; no
boxed widgets; motion on `transform`, `opacity`, `clip-path`, eased expo/power4 out,
0.8 to 1.4s, staggers 0.04 to 0.08s; everything motion-related is off under
`prefers-reduced-motion`; no overflow at 360px; keyboard access for every demo.

### Phase R1: foundations

- **Goal:** the new type scale, the section colour wipe, Lenis driving ScrollTrigger, line-by-line text reveals, and the dot cursor exist and are tested.
- **Why:** every later composition is built from these; changing them afterwards means restyling each section twice.
- **Files:** `package.json` (gsap), `app/globals.css`, `components/SmoothScroll.tsx`, `components/Motion.tsx` (new), `components/Cursor.tsx`, `components/Header.tsx`, `components/ThemeWatcher.tsx`, `app/layout.tsx`, `app/tokens.test.ts`, e2e files for cursor, theme, scroll.
- **Steps:** install gsap; replace type tokens and add the `label` utility; brighten `muted` on dark themes and extend the contrast test to 7:1 there; sections self-theme with a wipe layer; `Motion` wires `[data-wipe]`, `[data-lines]`, `[data-scale-in]`, `[data-bar]`, `[data-tilt]`; rebuild the cursor; fix tests.
- **Done when:** `pnpm test` passes and the cursor, theme and scroll browser tests pass.

### Phase R2: hero

- **Goal:** the particle sphere is large, centred and behind the full-width name; particles burst out on load and spring away from the pointer; the hero is pinned for a screen while the name shrinks into the header and the sphere flies down.
- **Why:** it is the first thing a juror sees and touches.
- **Files:** `components/Hero.tsx`, `components/Particles.tsx`, `components/ParticleStage.tsx`, `lib/shapes.ts`, `app/globals.css`, `scripts/record-hero.mjs` (re-record), `e2e/hero.e2e.ts`, `e2e/particles.e2e.ts`, `e2e/loader.e2e.ts`.
- **Done when:** the hero, particle and loader tests pass and the hero has been looked at on desktop and phone.

### Phase R3: work index

- **Goal:** huge full-width project names; hovering dims the others, tints the section and shows a media preview that trails the pointer; a 12-column asymmetric grid view.
- **Files:** `lib/media.ts` (new), `components/MediaSlot.tsx` (new), `components/WorkIndex.tsx`, `app/page.tsx`, `e2e/work.e2e.ts`.
- **Done when:** the work tests pass.

### Phase R4: chapters

- **Goal:** five chapters with five different compositions: Odovox in three screens with a tilting browser frame, a sticky demo beside the recording and giant counters; Road Damage over full-bleed video with a full-width chart; Kattral as a pinned horizontal strip; Edge Cache centred on three racing numbers; Hallucination as one giant question.
- **Why:** the brief's main complaint is that every section looks the same and like an admin widget.
- **Files:** `components/chapters/*.tsx` (five, new), `components/Frame.tsx` (new), `components/demos/*` (restyled, behaviour kept), `components/Chapter.tsx` (removed), `e2e/demos.e2e.ts`, `e2e/work.e2e.ts`.
- **Done when:** every demo test passes by keyboard and each chapter has been looked at.

### Phase R5: case studies

- **Goal:** the case-study page has rhythm: full-bleed media, a large intro, statements with a display-size number each, a drawn architecture diagram, a gallery, an inverted "where it broke" panel and a huge next-project link.
- **Files:** `app/work/[slug]/page.tsx`, `components/Flow.tsx`, `content/projects.ts` (media lists), `e2e/case.e2e.ts`.
- **Done when:** the case tests pass.

### Phase R6: about, contact, transitions, quality

- **Goal:** large portrait, bio at h3, skills as big lines; a huge email with copy-to-clipboard; underlined form fields; the page wipe followed by the next title rising; then accessibility, reduced motion, phone and Lighthouse re-checked.
- **Files:** `components/About.tsx`, `components/Contact.tsx`, `components/Wipe.tsx`, `DESIGN.md`, `docs/lighthouse/`, e2e files.
- **Done when:** the full pipeline exits 0, axe reports no violations, and Lighthouse mobile is 90 or more on the home page and a case study.
